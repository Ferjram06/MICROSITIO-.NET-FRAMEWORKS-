SOBRE EL PROYECTO

Una guía creada para aprender y avanzar.

Campus Guía es un micrositio universitario desarrollado como práctica de integración de tecnologías para aplicaciones web.

Objetivo

Centralizar recursos académicos y facilitar la navegación entre secciones.

Experiencia

Ofrecer una interfaz clara, adaptable y sencilla de utilizar.

Tecnología

Integrar frameworks de frontend con una API desarrollada en .NET.
